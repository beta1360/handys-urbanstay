# 코드 규칙

프론트엔드와 백엔드에 공통으로 적용하는 코드 작성 규칙. 프로젝트별 적용 방식은 각 프로젝트의 CLAUDE.md에 둔다.

## 상수

- 의미 있는 값은 코드에 직접 쓰지 않고 따로 관리한다.
  - 사용자에게 나가는 문구(응답 메시지, 화면 문구)는 메시지 파일로 관리한다.
  - 설정값과 기준 숫자(예: 페이지 크기, 제한값)는 이름 있는 상수나 설정 파일로 관리한다.
- 예외
  - 로그 문구는 코드에 둔다.
  - 테스트의 입력값·기대값 리터럴은 허용한다. 단, 운영 코드의 메시지는 테스트에 복사하지 않고 메시지 파일에서 읽는다.
